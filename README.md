# 课设协作台 · 多智能体协作的课程设计文档生成与评审系统

《软件工程》2026-2027 第一学期期末项目报告与设计资料。

## 项目概述

面向软件工程课程设计场景，把「分工—评审—收敛」的多智能体协作机制收窄到文档生成与评审：
需求分析师、架构师、测试工程师三个角色按固定顺序发言，仲裁者统计新增意见判定收敛，
文档工程师按报告模板拆解汇编，最终产出可提交的 Word 报告。系统为每条需求、每条架构建议
保留来源引用，任务全过程可回放，并按 token 预算与轮次上限控制成本。

## 设计要点

- **角色边界**：一个智能体 = 一次带角色卡的模型会话 + 一组受限工具权限 + 一段只读上下文。
- **可追溯**：产物携带 `source_ref`，指向输入原句或上游产物条目。
- **成本约束**：单任务默认预算 0.8 元，按实际 token 结算，超限即中止并如实标注。
- **增量修订**：第二轮起只重写受影响条目，单轮 token 消耗约为首轮三成。
